# Fiore florist — Next.js template

This folder is a standard Next.js 16 App Router project with Tailwind styles, florist components, original image assets, a dependency lockfile, and an environment example.

## Run locally

1. Install Node.js 20.9 or later.
2. From this folder, run `npm install`.
3. Copy `.env.example` to `.env.local`.
4. Run `npm run dev` and open http://localhost:3000.

```bash
npm install
cp .env.example .env.local
npm run dev
```

Build: `npm run build`  
Start production: `npm run start`  
Lint: `npm run lint`

Personalize `src/siteConfig.ts`, `src/lib/content.ts`, and the page/component copy. Read README.md for integration setup and photography sources. Photographs are demo references with unverified reuse rights; replace or license them before commercial publication.

All editable images are in `public/images/`.
